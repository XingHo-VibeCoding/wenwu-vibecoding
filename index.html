电子设备使用指南

写给用 Android 手机 + Windows 电脑的理工科学生：每件事分几步、每步多难、要多久，动手前先看清楚。

S1 实验数据传电脑 S2 电脑文件传回手机 S3 大文件传输 S4 资料两端同步 资源入口

S1 实验数据 / 板书传电脑

手机拍的实验数据、板书照片怎么进电脑、进报告。

适用：Android + Windows
前置条件：一根能传数据的 USB 数据线（很多线只能充电，不能传文件） 总耗时：待实测

  1. 用数据线连接手机与电脑。手机通知栏会弹出「USB 用途」提示——点开它，选择「传输文件」。不选的话，电脑那边只能看到手机在充电。

    难度：待实测 ｜ 耗时：待实测

    坑：电脑完全没反应，九成是数据线只能充电——换一根再试；传文件期间保持手机亮屏解锁，锁屏后设备可能从电脑上消失。

  2. 电脑打开「此电脑」，设备列表里会出现你的手机（显示为品牌名，如 HUAWEI / Xiaomi）——双击进入，再进「内部存储」。

    难度：待实测 ｜ 耗时：待实测

  3. 进入 DCIM → Camera 文件夹，这里是你手机相机的原图，实验数据和板书照片都在里面。

    难度：待实测 ｜ 耗时：待实测

  4. 选中需要的照片，复制到电脑上的报告文件夹。建议按实验日期建子文件夹（如 2026-09-21-实验三），报告写到一半也好找。

    难度：待实测 ｜ 耗时：待实测

  5. 传完先在电脑任务栏「安全弹出」手机（或把手机通知栏的 USB 用途改回「仅充电」），再拔线——直接拔偶尔会损坏正在传输的文件。

    难度：待实测 ｜ 耗时：待实测

S2 电脑文件传回手机

报告、资料发到手机上预览、提交前检查。

适用：Android + Windows
前置条件：手机和电脑连同一个 Wi-Fi；两端装 LocalSend（开源免费，见资源入口） 总耗时：待实测

  1. 两端各装 LocalSend：手机在应用商店搜「LocalSend」，电脑去官网 localsend.org 下载安装包。

    难度：待实测 ｜ 耗时：待实测

  2. 确认手机关掉移动数据、与电脑连的是同一个 Wi-Fi——两端不在一个网里，后面全部白做。

    难度：待实测 ｜ 耗时：待实测

    坑：搜不到对方设备时，先查路由器是否开了「AP 隔离」（部分校园网区域会开）；急用可改开手机热点，让电脑连热点组网。

  3. 电脑端 LocalSend 点「发送」，选中要传回手机的文件（报告、课件、资料都行）。

    难度：待实测 ｜ 耗时：待实测

  4. 在设备列表里点你的手机头像 → 手机端立刻弹出接收请求 → 点「接收」。

    难度：待实测 ｜ 耗时：待实测

  5. 文件落在手机「下载 / LocalSend」目录，通知栏直接点开就能预览——提交作业前最后过目一遍就用这步。

    难度：待实测 ｜ 耗时：待实测

S3 大文件传输

实验视频、安装包这类聊天工具传不动的大文件怎么传。

适用：Android + Windows
前置条件：任一网盘账号（百度网盘 / 阿里云盘等），电脑端用客户端或网页版 总耗时：待实测

  1. 电脑端把大文件上传到网盘。建议先建一个「中转」文件夹专门放这类文件，传完好清理。

    难度：待实测 ｜ 耗时：待实测

    坑：单个文件超过网盘免费上限（常见 4GB）传不上去——先用压缩工具「分卷压缩」切成几段，到手机端再解压合并。

  2. 等上传进度走到 100% 再干别的——中途电脑休眠或关机，传一半的文件等于没传。

    难度：待实测 ｜ 耗时：待实测

  3. 手机安装同一个网盘 App，登录同一账号。

    难度：待实测 ｜ 耗时：待实测

  4. 在 App 的「中转」文件夹里找到文件，下载到手机本地（别只在云端预览，预览≠保存）。

    难度：待实测 ｜ 耗时：待实测

  5. 核对：对比手机显示的文件大小和电脑端是否一致，一致才删掉云端中转文件——不一致重传，别赌。

    难度：待实测 ｜ 耗时：待实测

S4 资料两端同步

代码、笔记等学习资料在手机和电脑间的日常同步。

适用：Android + Windows
前置条件：选定一个同步盘（OneDrive 或坚果云），两端登录同一账号 总耗时：待实测

  1. 电脑安装同步盘客户端并登录，记牢同步文件夹的位置——之后放进这个文件夹的一切都会自动上传。

    难度：待实测 ｜ 耗时：待实测

  2. 把代码、笔记等资料移进同步文件夹。注意是移动进去，不是留个快捷方式——快捷方式不会被同步。

    难度：待实测 ｜ 耗时：待实测

  3. 手机安装对应的 App 并登录同一账号，测试：电脑端放一个文件进去，看手机端能不能刷出来。

    难度：待实测 ｜ 耗时：待实测

  4. 日常用法：电脑改完文件 → 等客户端图标显示「已同步」→ 手机端下拉刷新即是最新版。写报告到一半去图书馆，手机上接着看就是这么来的。

    难度：待实测 ｜ 耗时：待实测

  5. 手机上查看或编辑后，务必保存回 App 的同步目录——存到手机相册或其他目录的改动，电脑端收不到。

    难度：待实测 ｜ 耗时：待实测

    坑：同步盘不是备份——电脑上误删会同步删掉，重要资料每周手动另存一份到别的盘；两端同时改同一文件会产生「冲突副本」，以修改时间新的为准。

官方 / 实用资源入口

  • Android 官方帮助 —— 手机系统设置、USB 传输模式的官方说明，S1 第 1 步卡住先查这里
  • Microsoft Windows 支持 —— 「此电脑」「文件资源管理器」和驱动问题的官方文档
  • LocalSend 官网 —— S2 用的局域网传输工具，开源免费、无广告
  • 百度网盘官网 —— S3 大文件中转用的网盘，客户端下载入口
  • OneDrive 帮助 —— S4 同步盘的官方设置指南（Windows 自带，登录即用）
  • 坚果云帮助中心 —— 国内同步盘官方文档，对网速敏感时的 OneDrive 替代

卡住了找谁：照做失败时，先回到对应步骤的"注意事项"检查；仍解决不了，用"资源入口"里的官方支持页搜索报错信息。
